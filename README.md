# earth_photo_manager
写真管理アプリ。  
強力なタグ付け機能やTweet向け機能などユニークな機能を多数搭載している。

使い方は以下。  
https://github.com/dj-kata/earth_photo_manager/wiki/%E4%BD%BF%E3%81%84%E6%96%B9

## for developers
### 実行

```sh
uv run python earth_photo_manager.pyw
```

### ビルド

`.env.sample` を `.env` にコピーして `WUV` を設定したあと、以下を実行します。

```sh
make
```

## 現在の機能

- 複数のルートフォルダ登録
- 登録ルート配下のサブフォルダ閲覧
- 選択中フォルダ直下の画像ファイル一覧
- サムネイル付きファイル一覧
- 別プロセスでバックグラウンド生成されるサムネイルキャッシュ
  - アプリルート内の `data/thumbnail/` に保存
  - 未完了分は次回起動後にバックグラウンドで再開
- 同一ウィンドウ内プレビュー
- 別ウィンドウプレビュー切り替え
- 選択中画像のファイル情報表示
- タグ・タグカテゴリ・画像へのタグ付け
  - アプリルート内の `data/earth_photo_manager.db` に保存
- 前回選択していたフォルダ・画像の復元
- 前回のウィンドウサイズ・最大化状態・分割位置の復元
